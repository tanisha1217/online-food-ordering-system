# Online Food Ordering System

## Project Overview

This project is an Online Food Ordering System built using Object Oriented Programming concepts.
It represents how a food ordering application works at a basic level, including restaurants, customers, orders, payments, and delivery.

The main focus of this project is on designing the system in a structured way by identifying proper classes, their responsibilities, and the relationships between them.
Before starting the implementation, the complete design was planned using UML class diagrams.

## Features

* Customer registration and login
* Restaurant and food item listing
* Order placement and order status tracking
* Payment handling
* Delivery assignment
* Feedback and rating system

## OOPS Concepts Used

* **Encapsulation**
  Class data is kept private and accessed using methods.

* **Inheritance**
  Common properties are defined in base classes and reused in derived classes.

* **Association and Composition**
  Used to represent relationships like customers placing orders and orders containing food items.

* **Abstraction**
  Different parts of the system interact through well-defined interfaces.


## System Design

The system design is represented using UML class diagrams, which help in understanding the structure of the application and the interaction between different classes.

All design-related files are available in the `docs/` folder.
